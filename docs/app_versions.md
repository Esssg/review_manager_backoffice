# 앱 버전 이력

앱 실행 기준은 `src/constants/appVersion.ts`, 배포 메타데이터는 `package.json`의 `version`으로 관리합니다.

## 1.0.1 — 2026-08-14

- 상품전체보기 사진 미리보기 모달에 행 정보와 사진 영역을 2열로 표시
- 현재 필터 결과 전체 기준 이전·다음 사진 이동, 미로드 결과 lazy fetch, 좌우 화살표 키 지원
- 사진 삭제 확인창의 레이어·focus·busy 상태 보완
- 계정별 버전 튜토리얼 진행 상태와 스킵/완료 처리 추가
- 튜토리얼: 상품전체보기 진입, 사진 필터, 사진 모달 정보·사진·삭제·이전·다음·키보드 안내
- 튜토리얼 기준 버전: `1.0.1`

## 1.0.0 — 2026-08-14

- 상품전체보기 및 기존 사진 미리보기 기능의 기준 버전
- 버전별 계정 튜토리얼을 도입하기 전의 초기 기준점
